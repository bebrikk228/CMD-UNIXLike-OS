# Эмулятор командной строки UNIX-подобной ОС (Вариант 28)

## 1. Общее описание
Данное приложение является графическим эмулятором языка оболочки UNIX-подобной ОС, выполненным в ретро-стиле интерфейса Windows 95. Эмулятор работает с виртуальной файловой системой (VFS), загружаемой из CSV-файла, и выполняет все операции изменения структуры строго в оперативной памяти.

## 2. Описание всех функций и настроек
### Поддерживаемые команды:
* `ls` — вывод содержимого текущего каталога VFS.
* `cd <путь>` — переход в указанный каталог VFS (`..` для возврата назад).
* `pwd` — вывод абсолютного пути текущего рабочего каталога.
* `echo <текст>` — вывод строки аргументов на экран.
* `mv <исходный> <целевой>` — переименование или перемещение объекта в памяти.
* `chown <владелец> <объект>` — смена владельца объекта в памяти.
* `exit` — корректное завершение работы приложения.

### Параметры запуска:
Приложение принимает конфигурационные параметры через аргументы командной строки:
* `--config` — путь к конфигурационному INI-файлу (имеет наивысший приоритет).
* `--vfs` — путь к физическому расположению CSV-файла виртуальной файловой системы.
* `--script` — путь к стартовому скрипту для автоматического выполнения команд.

## 3. Описание команд для сборки проекта и запуска тестов
Для работы приложения необходим Python 3 и библиотека PySide6.

### Запуск тестов:
```bash
python3 -m unittest discover tests
```

### Запуск приложения:
```bash
python3 main.py --config config.ini
```

## 4. Примеры использования
Пример интерактивного сеанса в эмуляторе:
```bash
\$ pwd
/
\$ ls
home  etc
\(cd home\) pwd
/home
\$ echo Тест системы
Тест системы
```
