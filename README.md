# Эмулятор командной строки UNIX-подобной ОС (Вариант 28)

## 1. Общее описание
Данное приложение является графическим эмулятором языка оболочки UNIX-подобной 
ОС, выполненным в стиле интерфейса Windows 95. Эмулятор работает с виртуальной 
файловой системой (VFS), загружаемой из CSV-файла, и выполняет все операции 
изменения структуры строго в оперативной памяти. Проект разработан в рамках 
дисциплины «Конфигурационное управление».

## 2. Описание всех функций и настроек
### Поддерживаемые команды:
* `ls` — вывод содержимого текущего каталога VFS.
* `cd <путь>` — переход в указанный каталог VFS (`..` для возврата назад).
* `pwd` — вывод абсолютного пути текущего рабочего каталога.
* `echo <текст>` — вывод строки аргументов на экран.
* `mv <исходный> <целевой>` — переименование или перемещение объекта в памяти.
* `chown <владелец> <объект>` — смена владельца объекта в памяти.
* `exit` — корректное завершение работы приложения.

### Параметры конфигурации (config.ini):
* `vfs_path` — путь к CSV-файлу виртуальной файловой системы.
* `script_path` — путь к стартовому текстовому скрипту команд (например, `start.sh`).

## 3. Описание команд для сборки проекта и запуска тестов
Проект полностью кроссплатформенный и имеет встроенные скрипты автоматизации.

### Запуск на Linux / macOS:
```bash
./run.sh
```
*Скрипт автоматически проверит зависимости, запустит модульные тесты 
и откроет эмулятор.*

### Запуск на Windows:
Дважды кликните по файлу **`run.bat`** в корневой директории проекта.

## 4. Примеры использования
Пример выполнения автоматического стартового скрипта при запуске:
```text
=== [1/3] Проверка и установка зависимостей ===
=== [2/3] Автоматический запуск модульных тестов ===
Ran 5 tests in 0.001s - OK
=== [3/3] Запуск UNIX Эмулятора ===
VFS Status: VFS успешно загружена в память.
\$ ls
home  etc
\$ pwd
/
```
