# Эмулятор командной строки UNIX-подобной ОС (Вариант 28 - Этап 1)

## 1. Общее описание
Данное приложение представляет собой минимальный прототип графического 
эмулятора командной строки UNIX-подобной ОС (REPL), выполненный в стиле 
пользовательского интерфейса Windows 95 на базе библиотеки PySide6 (Qt). 
Проект разработан в рамках дисциплины «Конфигурационное управление».

## 2. Описание всех функций и настроек

### Поддерживаемые команды:
* ls — команда-заглушка (выводит свое имя и переданные аргументы).
* cd — команда-заглушка (выводит свое имя и переданные аргументы).
* exit — корректное завершение работы эмулятора.

## 3. Описание команд для сборки проекта и запуска тестов

### Запуск на Linux / macOS / Windows:
PYTHONPATH=src python3 src/main.py

### Запуск тестов вручную:
PYTHONPATH=src python3 -m unittest discover tests
