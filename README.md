# Эмулятор командной строки UNIX-подобной ОС (Вариант 28 - Этап 4)

## 1. Общее описание
Данное приложение представляет собой графический эмулятор языка оболочки 
UNIX-подобной ОС, выполненный в стиле пользовательского интерфейса Windows 95 
на базе библиотеки PySide6 (Qt). Эмулятор взаимодействует с виртуальной 
файловой системой (VFS), загружаемой из CSV-файла, и выполняет все операции 
исключительно в оперативной памяти. Проект разработан в рамках дисциплины 
«Конфигурационное управление».

## 2. Описание всех функций и настроек

### Поддерживаемые команды:
* ls [-l] [-a] [-h] [путь] — вывод содержимого каталога VFS с поддержкой комбинированных флагов (-la, -lah), отбраковкой некорректных опций и поддержкой формата человекочитаемого размера объектов.
* cd <путь> — переход в указанный каталог VFS (.. для перехода на уровень выше, без аргументов — переход в корень /).
* pwd — вывод абсолютного пути текущего рабочего каталога.
* echo <текст> — вывод строки аргументов на экран с поддержкой кавычек и переменных окружения.
* clear — очистка текстового поля вывода терминала.
* exit — корректное завершение работы эмулятора.

### Параметры конфигурации и логика приоритетов:
Параметры запуска передаются через аргументы командной строки и INI-файл конфигурации (config.ini).
По требованию ТЗ значения из конфигурационного файла INI имеют строго высший приоритет над аргументами командной строки.

* --vfs <путь> / vfs_path — путь к CSV-файлу источника VFS.
* --script <путь> / script_path — путь к стартовому скрипту команд эмулятора.
* --config <путь> — путь к конфигурационному файлу INI.

### Формат INI-файла (config.ini):
[Setting]
vfs_path = vfs.csv
script_path = start.sh

## 3. Описание команд для сборки проекта и запуска тестов
Приложение является кроссплатформенным. Скрипты автоматизации обеспечивают проверку зависимостей, проброс путей модулей (PYTHONPATH=src) и автозапуск модульных тестов перед открытием эмулятора.

### Запуск на Linux / macOS:
chmod +x run.sh
./run.sh

### Запуск на Windows:
run.bat

### Запуск тестов вручную:
PYTHONPATH=src python3 -m unittest discover tests
